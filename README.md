# Moodle Study Assistant · 轻量版

给同学使用的 **Windows 本地学习助手**：连接自己的 Moodle，检查作业和通知，结合本人课件讲解、排计划、记错题、安排复习与考前练习。每个人从空白档案开始。

**[下载源码包](https://github.com/jiangzengyuang-jisoo/moodle-study-assistant-lite/releases/latest) · [新手教程](docs/新手使用指南.md)**

> 需要能访问本地文件和运行工具的 AI 客户端，例如 Codex 的本地项目模式。只在浏览器打开本仓库不会启动助手。本项目不要求另填模型 API Key；所用 AI 客户端的账号、订阅及额度另行适用。

## 从零开始

| 顺序 | 做什么 | 成功标志 |
|---|---|---|
| 1 | 安装 [Node.js](https://nodejs.org/en/download) 22+、[Python](https://www.python.org/downloads/windows/) 3.11+；准备支持本地项目的 AI 客户端 | 具体安装方法见教程 |
| 2 | 下载 Release 中的 `moodle-study-light-source.zip`，**全部解压**到固定文件夹 | 能看到 `setup.cmd` 和 `AGENTS.md` |
| 3 | 双击 `setup.cmd` | 出现 `Setup complete` |
| 4 | 双击 `connect.cmd`，在学校网页中本人登录、完成验证 | 出现“Moodle API 已验证并加密保存” |
| 5 | 双击 `choose-courses.cmd`，输入自己课程的数字 ID | 课程选择完成 |
| 6 | 双击 `refresh.cmd`，再在 AI 客户端打开此文件夹，发送下面的话 | AI 核读通知，并说明已确认信息与待确认事项 |

默认 HKU Moodle。其他学校、连接失败、打开项目等详细操作见 **[新手教程](docs/新手使用指南.md)**。不要把学校密码或 Token 发给 AI。

### 第一句话直接复制

```text
请先阅读这个文件夹的 AGENTS.md，按轻量版规则初始化我的学习助手。
先检查安装、连接和选课情况；已完成的步骤不用重做。
检查全部已选课程的新通知，实际核读后再更新学习记录，失败或没读完的要明确告诉我。
再问我必要的学习进度、已交作业和可用时间，帮我生成今天的初步计划。
未知的信息保持待确认，不要把“已经讲过”当作“我已经掌握”。
```

把自己的课件或题目放进 `Study/_Inbox/`，告诉 AI“请整理这些材料”。首次安装没有个人题库；需要根据自己的材料准备练习。

## 平时怎么用

- “看看今天作业和通知有什么变化，我只有 90 分钟，先安排重要的。”
- “接着学微观，用老师的课件讲，再让我独立做一道。”
- “这一步没懂，换一个简单例子。”
- “开始 15 分钟复习，先不给答案。”
- “小组作业由同伴交了，请记录，不要因为我个人账户没记录又安排一次。”
- “按老师公布的考试范围和题型出模拟卷；缺材料或未公布的要求请说明。”

每条学习消息（包括追问）都会检查 Moodle；只有用户明确接受时才使用缓存。项目设置咨询不触发学校访问。关闭项目后没有后台检查，因此它**不是全天候推送软件**。

## 怎样减少 Token

按课程读取必要内容；程序在本地比较学校变化，AI 重点核读待审来源。未读版本持久保留，图片、附件和权限问题不能用一句“无变化”略过。

合成数据分词实测：单课上下文比整份状态减少 **79.0%–94.7%**；“首次同步 + 9 次无变化通知检查”合计减少 **64.2%**。**首次完整同步可能更贵**。这些是本地输入/输出文本的计数，不是完整 AI 会话或 Plus 额度测量，不能承诺额度多用多少倍。口径和全部结果见 [验收记录](docs/VALIDATION.md)。

## 通知与功能边界

- 保留教学、学习计划、错题、FSRS 复习、计算核验、考试覆盖与模拟卷流程。
- 跟踪所有已选课程的 API 可见通知，保留编辑历史，核对教师身份、正文限定和媒体；采集成功不代表已经核读。
- 普通日历检查范围为当前起 **31 天**。未选课程、学校未开放的内容及无法核读的媒体不能声称已覆盖；失败必须标待确认。
- 已通过 227 项回归及独立目录安装检查，使用空白档案与合成数据。尚未完成本轻量版在真实学校 SSO/MFA、权限与实时通知上的端到端验证。其他学校是否支持取决于其 Moodle 移动服务/API。

## 数据留在哪里

学习记录在本机 `Study/`；学校授权用本人 Windows 账户加密，位于 `.private/`。AI 客户端读取的材料可能发送给其模型服务商，本地保存不等于离线推理。

不读取浏览器 Cookie；不自动下载课件、提交作业、发帖、发邮件或建立后台任务。备份须保留**整个 `Study/`**，包括通知来源档案 `notification-journal.sqlite3`。

**分享仓库链接或干净源码包，不要分享用过的整个文件夹。** `Study/`、`.private/`、本机配置、虚拟环境和依赖均不属于公开源码。源码包通过 `package-source.ps1` 的白名单生成。
