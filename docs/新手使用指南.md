# 新手教程：从下载到第一次学习

适用：Windows；默认 HKU Moodle。你不需要懂编程，但需要自己完成学校登录与验证。项目不附任何人的账号、课程文件、讨论内容或学习记录。

## 1. 先准备三个工具

1. **Node.js 22 或更新版本**：打开 [官方下载页](https://nodejs.org/en/download)，选择 Windows 的 LTS 安装包，按默认选项安装，保留 npm。
2. **Python 3.11 或更新版本**：打开 [官方下载页](https://www.python.org/downloads/windows/)。使用传统安装器时勾选 **Add Python to PATH**；使用 Python 安装管理器时，按官方提示安装可用的 Python 版本。安装后关闭并重新打开项目窗口。
3. **支持本地项目的 AI 客户端**：例如 Codex 的本地项目模式。按 [OpenAI 官方入门指南](https://developers.openai.com/codex/quickstart)安装适合 Windows 的客户端并登录。客户端名称与按钮可能随版本更新。

本项目负责本地工具和学习档案；AI 客户端负责讲解和执行工具。无需为本项目另填模型 API Key，但客户端自身的订阅、可用功能和额度仍适用。只有普通网页聊天、没有本地访问能力时，无法直接运行本项目。

## 2. 下载，全部解压

1. 打开 [下载页面](https://github.com/jiangzengyuang-jisoo/moodle-study-assistant-lite/releases/latest)。
2. 展开 **Assets**，下载 **moodle-study-light-source.zip**。
3. 右键压缩包，选择“全部解压”，放到固定位置，例如 `D:\MoodleStudyLite`。
4. 打开解压后的文件夹，确认能看到 `setup.cmd`、`README.md`、`AGENTS.md`。

也可在 [仓库首页](https://github.com/jiangzengyuang-jisoo/moodle-study-assistant-lite)点 **Code → Download ZIP**。这种下载会多一层文件夹，请进入真正包含 `setup.cmd` 的那一层。

**不要直接在压缩包里双击程序，也不要覆盖自己原来的学习项目。** 轻量版应使用独立文件夹。

## 3. 安装本地助手

双击 **setup.cmd**。首次安装需要联网下载依赖，可能需要几分钟；窗口还在输出时耐心等待。

成功标志是 **Setup complete**。此时会生成本人的空白 `Study/`、本机配置和运行环境。初次安装不会带入作者或其他同学的数据，也不会连接学校。

如果显示失败，先看窗口上面的报错，不要把最后的“按任意键继续”当成功。后文有常见问题表。

## 4. 本人连接学校

HKU 同学直接双击 **connect.cmd**。程序打开新的 Edge 登录窗口，你在学校网页里自己输入账号、密码并完成验证（例如手机确认）。

成功标志是 **“Moodle API 已验证并加密保存”**。之后刷新使用官方授权，不必每次输入学校密码；授权失效时重新连接。

程序不读取你现有浏览器的 Cookie，不保存学校密码，不把授权内容显示给 AI。**不要把密码或 Token 发到聊天里。**

### 非 HKU 同学

先用记事本打开安装生成的 `config.local.json`，把 `moodle_url` 改为自己的 Moodle 首页，例如 `https://moodle.example.edu`，保存后再连接。不要填某门课程链接或带登录参数的网址。

时区默认香港。其他地区可让 AI 协助将本机配置和学习状态的 timezone 一致设置为正确 IANA 时区；已有日期需逐项核对，不能直接全部平移。

**兼容性限制：**本轻量版的登录组件已做合成测试，但尚未完成真实学校 SSO/MFA 的端到端验证。学校必须开放相应的移动服务/API；不是所有 Moodle 站点都能连接。

## 5. 选自己的课程

双击 **choose-courses.cmd**。窗口会列出你有权访问的课程及数字 ID。

输入想跟踪的课程 ID，用逗号分开。例如窗口真的有 101 和 102 才输入 `101,102`，不要照抄示例号码。

- 选择本学期需要跟踪的课程；未选课程不在检查范围内。
- 同一科如果有公共页和班级页，通常需要都选。请让 AI 核对后合并为同科，并保留全部 Moodle 课程 ID；不确定就先保留两条。
- 增减选课时重新运行此入口，核对提示，不把退选等同于删除历史记录。

## 6. 第一次检查通知

双击 **refresh.cmd**。它会读取所选范围的作业、测验、论坛与日历，保存可用信息；不会自动下载课程文件。

程序采集和 AI 核读是两步：**刷新没有报错，不等于 AI 已经读完所有重要通知。**

看到待审数量不是失败。下一步让 AI 逐页核读全部课程的新内容，包括教师身份、正文条件、图片与附件。读取失败、权限不足或媒体看不到时，必须保留“待确认”，不能宣称全部检查完毕。

普通日历检查当前起 31 天。关闭项目后不会继续检查，也不会向你推送消息。

## 7. 在 AI 客户端打开项目

1. 在客户端选择添加/打开本地项目，选中**含有 AGENTS.md 的文件夹**。
2. 确认这是你刚下载的项目，允许客户端在这个项目中使用必要的本地文件和工具。
3. 新建一段项目对话，复制以下文字发送：

```text
请先阅读这个文件夹的 AGENTS.md，按轻量版规则初始化我的学习助手。
先检查安装、连接和选课情况；已完成的步骤不用重做。
检查全部已选课程的新通知，实际核读后再更新学习记录，失败或没读完的要明确告诉我。
再问我必要的学习进度、已交作业和可用时间，帮我生成今天的初步计划。
未知的信息保持待确认，不要把“已经讲过”当作“我已经掌握”。
```

4. 按实际情况告诉 AI：哪些作业已经交、是否小组代交、学到哪里、哪里没懂、今天有多少时间。
5. 把自己的课件/PDF/题目放到 `Study/_Inbox/`，告诉 AI：“请整理这些材料，按老师的方法教学。”

第一次没有个人题库或历史作答，显示没有待复习题是正常的。先让 AI 根据自己的材料准备题目，再通过真实独立作答建立复习记录。

### 如何判断真的装好了

- AI 能识别你的已选课程，并说明本次学校检查结果。
- AI 对已核读内容给出结论，对失败或未读完内容明确说明。
- 初步计划使用你提供的时间与进度；缺信息会询问，不凭空补全。
- 你的记录出现在自己的 `Study/`，而不是作者或其他项目目录。

没有通知变化不代表连接失败；是否成功以本次采集状态为准。只有安装检查通过，也不代表学校接口已经验证。

## 8. 以后直接这样说

```text
看看今天最新作业和通知。我今天只有 90 分钟，先安排最重要的事。
```

```text
接着学会计。先用老师课件解释，再让我独立做一道，暂时不要给答案。
```

```text
这一步没懂，请换一个简单例子，再出一道变式题。
```

```text
这份小组作业由同伴交了。不要因为我个人账户没有提交记录又安排一次。
```

```text
开始 15 分钟复习。答完再评价；刚看过答案的题不要算成独立掌握。
```

```text
按老师公布的考试范围和题型出模拟卷。先核对通知和我的课件；缺材料或未公布的要求请说明。
```

每条学习消息（含追问）都会触发实时检查；同一天也不会跳过。项目设置咨询不会访问学校。第一次核读可能较慢、较费 Token，以后无变化时返回更短。不要为了省 Token 要求忽略未读通知。

## 9. 常见问题

| 遇到的情况 | 处理方法 |
|---|---|
| 找不到 node/npm，或版本太旧 | 安装 Node.js 22+，保留 npm；关闭窗口后重新打开，再运行 setup.cmd |
| 找不到 Python，或打开了商店 | 按官方页面安装 Python 3.11+；传统安装器勾选 PATH；重新打开窗口后再安装 |
| 安装下载失败/超时 | 检查网络后重新运行 setup.cmd；它会保留已有档案，不需要删除 Study |
| 登录窗口没有打开 | 确认 setup 成功、电脑有 Edge；只有 Chrome 时使用下面的备用命令 |
| invalidtoken / 授权失效 | 核对学校首页地址，再运行 connect.cmd，由本人重新登录 |
| 学校网页能登录，但 API 拒绝或无权限 | 向学校 IT 确认移动服务/API 是否开放；不能靠抓 Cookie 解决 |
| 课程列表少了一门 | 确认本人在 Moodle 网页能访问且已正确选课；API 不返回的内容保持待确认 |
| 有待审项、部分采集失败、图片看不到 | 让 AI 说明缺口并保留待审；恢复权限/连接后再读，不能强行标“已检查” |
| AI 只聊天，没有运行项目 | 检查是否打开正确的本地项目、客户端是否支持工具；让它先读 AGENTS.md 并检查安装 |
| 没有复习题/考试覆盖不完整 | 先提供课件、老师要求和真实作答；不会从空白档案凭空生成学习证据 |
| 移动文件夹后工具失效 | 让 AI 修正 .codex/config.toml 中的本机路径；安装器不会覆盖已有配置 |
| 换电脑后不能解密授权 | 在新电脑重新安装、连接学校；Windows 加密授权不应复制给别人 |

排错时把“做到哪一步＋错误文字”告诉 AI。公开发 Issue 前删掉姓名、学号、学校讨论正文和私人路径；不要附完整状态、密码或授权。

### 备用连接方式（需要时再看）

在项目文件夹地址栏输入 `powershell`，回车，再输入：

只有 Chrome 时：

```powershell
./connect.cmd --browser chrome
```

**已经有学校官方提供的 Moodle Web Service Token** 时：

```powershell
./connect.cmd --manual
```

仅在终端的隐藏输入处填写，不发给 AI。学校未提供官方 Token 时，不要猜测或提取浏览器 Cookie。

### MCP 未连接（需要时再看）

MCP 是让 AI 调用本地工具的方式。安装会生成 `.codex/config.toml`；项目须受信任后才能加载项目级配置。依据：[官方 MCP 说明](https://developers.openai.com/codex/mcp)。

在客户端的 MCP 设置中查看 `moodle_study`。必要时添加 STDIO 服务器：命令是本机 `node.exe`，两个参数分别是“项目完整路径/tools/moodle/run.mjs”和“mcp”，不要拼成一个参数。移动项目后须修正路径。

即使 MCP 暂时没有连接，支持本地执行的客户端也能按 AGENTS.md 运行学习工具。新手无需额外安装本仓库的 SKILL.md；它是另一种可选入口。

## 10. 备份、更新与分享

- 关闭正在运行的学习程序后，备份**整个 Study/**，包括 `_System/notification-journal.sqlite3`。它保存未读通知版本，不能当缓存删掉。
- 更新同一轻量版前先备份，再更新公开源码、运行 setup.cmd；不要把空白模板覆盖到自己的状态上。
- 从原版迁移到轻量版应保留原版独立目录，请 AI 先检查迁移方案，不要直接覆盖或盲目复制状态。
- 换电脑时迁移自己的学习档案，重新安装和连接；不复制分享授权。
- 给同学发仓库链接或 Release 源码包。**不要压缩分享自己用过的整份项目目录。**
- 学习资料在本地，但 AI 读入的内容可能发送给其模型服务商，按你使用的客户端政策处理。

本项目不自动提交作业、答题、发帖、发邮件或下载课件，不在后台运行。明确请求下载指定课件时，应核对范围并保留原件。
